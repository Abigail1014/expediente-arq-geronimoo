# ADR-001: Fusión de Strategy y Observer en Créditos

## Estado
Aceptado

## Contexto
El subsistema de créditos requiere flexibilidad matemática para calcular moras de acuerdo a normativas variables (Strategy) y notificar de manera reactiva a los gestores de cobranza (Observer).

## Decisión
Implementar una clase central `Cuota` que delegue las reglas de cálculo a `IEstrategiaMora` y gestione suscripciones mediante `IObserverCuotaVencida`.

## Consecuencias
- Desacoplamiento total entre las reglas de negocio financieras y el sistema de alertas.
- Facilidad para incorporar nuevas estrategias o canales de notificación.
